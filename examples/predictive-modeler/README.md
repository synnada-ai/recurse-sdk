# Predictive Modeler

An evidence-driven agent for predictive modeling across classification, regression, and forecasting.

## When to use it

Use it when model and feature choices should respond to measured experiments.
A direct implementation is simpler when the model configuration is already known.

## How the loop works

Check input consistency, resolve evaluation, train candidates, measure, revise, and finalize.

## Run it

Runnable real-data requests are being added with the modeling tools.

## Result

A prediction pipeline, experiment history, resolved contract, and evaluation report.

## Limitations

Model families and dataset formats are bounded; results do not establish global optimality.
